Header: Fica visível no corpo (body) da página e agrupa o topo visual ou o cabeçalho de artigos.

Main: define o conteúdo principal e único do corpo (body)

Nav: é um elemento semântico usado para criar uma seção de uma página dedicada a links de navegação, como menus principais, sumários ou índices.

Selection: ela serve para criar um menu suspenso (ou lista de opções) em formulários.

Article: define um artigo independente e pode ser reutilizado, como um post em um blog.

Aside: define um conteúdo secundário que está relacionado ao conteúdo principal, mas pode ser lido independentemente.

Figure: define uma figura, geralmente um elemento visual como uma imagem, que pode ser referenciada por um texto alternativo.

Footer: define o rodapé de uma página, contendo informações como direitos autorais, links para políticas de privacidade, etc.
